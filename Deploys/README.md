DevContainer = corre comandos a traves del plugin de MC.
* La imagen de docker va hacia GCR (Google artifact registry)
* En GAR, se crea en un repo, para publicar la imagen.
* Google cloud run (Instacia de nodos).
* Serverlees = concepto de mercado unicamente para vender (Que son apps sin servidor).
* El Serverlees es una maquina o una instacia de encendido y apagado cuando es requerida.
* El GCR (Google cloud run) es el encargado de correr el container que se genera a partir del Dockerfile.
